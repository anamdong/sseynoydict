# Hoe'im Tihy dictionary — GitHub Pages release

This folder is a self-contained static release. Its date is included in the folder name.

To publish it:

1. Upload **the contents of this folder** to the root of a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Set the deployment source to **Deploy from a branch**, then select the branch and its **/(root)** folder.
4. Save and wait for GitHub Pages to publish the site.

The four entry points are `index.html`, `sound-search.html`, `mc-tools.html`, and `text-reader.html`.
The dated initial–rhyme CSV and its statistics summary are included for reference; they are not required by the website.
